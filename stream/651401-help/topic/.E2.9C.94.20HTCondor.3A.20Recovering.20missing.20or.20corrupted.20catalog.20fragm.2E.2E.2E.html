Problem

In rare cases, HTCondor fails to transfer output files back to the working directory. This may result in:

  1. Corrupted catalog fragments after an unsuccessful transfer.

  2. Missing catalog fragments, where an existing file was removed but its replacement was not successfully transferred.

Solution / Workaround

pycWB provides the repair-catalog command to recover corrupted catalog fragments.

For a corrupted fragment that still exists:

pycwb repair-catalog config/user_parameters.yaml --work-dir . --fragment 12345 --apply

For a missing fragment, first create an empty placeholder file, then run the repair command:

touch catalog/fragment/catalog_12345.parquet
pycwb repair-catalog config/user_parameters.yaml --work-dir . --fragment 12345 --apply

Replace 12345 with the affected batch ID.

Note: The empty file is only a workaround to allow the repair procedure to process a missing fragment. It is not a valid Parquet file on its own. Verify the repaired fragment and catalog before continuing the analysis.

Status: Workaround available. The underlying HTCondor transfer failure is not addressed by this procedure.
