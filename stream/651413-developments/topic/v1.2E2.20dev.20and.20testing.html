The v1.2 cpu accelerated version is ready for testing, current preliminary testing shows no difference with v1.1.0rc1. To install, you can use

conda create -n pycwb-v1.2.0a1 -c conda-forge python=3.13 pip nds2-client python-nds2-client lalsuite python-ligo-lw
conda activate pycwb-v1.2.0a1

pip install  pycwb==1.2.0a1

It will use the wdm-wavelet=0.5.0a1.

Some post-processing packages are not included by default like XGBoost and rich
